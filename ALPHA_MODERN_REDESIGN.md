# ALPHA Shell Modern Redesign

This update documents the approved modern redesign direction for ALPHA Shell.

## Branding

- Use the Alpha7 esports logo as the ALPHA Shell brand logo.
- Move the visual identity toward a black/orange esports style.
- Keep the interface dark, sharp, premium, and modern.

## ALPHA Quick Launcher redesign

- Wider modern command-center panel.
- Dark glass-style background.
- Orange Alpha7-inspired accent color.
- Larger search field.
- Larger app icons.
- Cleaner result rows.
- Stronger selected-row highlight.
- Updated placeholder text: `Search apps, tools, settings…`.
- Empty state: `No apps found — try another search`.

## ALPHA Writer redesign

- Floating glass-style toolbar.
- More modern rounded buttons.
- Orange selected states.
- Cleaner section labels.
- Better spacing for tools, colors, widths, undo/redo, clear, and close.
- Branded header using ALPHA / Alpha7 style.

## Files planned for implementation

- `stylesheet.css`
- `ui/launcher.js`
- `ui/indicator.js`
- `metadata.json`
- `README.md`
- `media/alpha-logo.png` or `media/alpha-logo.svg`

## Status

The redesign direction has been prepared and previewed. The next implementation step is to wire the logo asset into the GNOME Shell indicator and apply the final CSS/JS changes.
